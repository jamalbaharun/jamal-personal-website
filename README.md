# Professional Portfolio Website

A premium, responsive personal portfolio website built with HTML5 and CSS3.

## Features
- **Modern Design**: Clean aesthetic with Inter typography and mesh gradients.
- **Glassmorphism**: Sticky navigation bar with blur effects.
- **Responsive**: Fully optimized for desktop and mobile devices.
- **Project Showcase**: specific sections for professional experience and published apps.

## Deployment to GitHub Pages

1. Create a new repository on GitHub (e.g., `my-portfolio`).
2. Run the following commands in this directory:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/my-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Go to Repository Settings -> Pages.
4. Select `main` branch as the source and save.
5. Your site will be live at `https://YOUR_USERNAME.github.io/my-portfolio/`.
